# FTV (OK 影视风格) 跨平台客户端重构指南

本项目参考 **OK 影视 (FongMi TV)** 架构全面重构，专注于 **FongMi 原生 JS 爬虫源** 高性能执行，支持 Windows、Linux、Android TV、手机与 iOS 多端统一体验。

---

## 一、本次核心升级与重构亮点

### 1. 结构精简与三大主 Tab 架构
- **页面合并**：彻底移除冗余的独立“首页”与“分类页”，统一定制为 **点播 (VOD)** 页面。
- **三大顶级导航**：底部主导航仅保留 **点播**、**直播**、**设置**，顶部保留全网搜索与推送解析入口。
- **无用代码清理**：彻底剔除已废弃的 `category/`、`home/`、`player/` 与非必要的 `cat.js` 依赖，纯粹基于 FongMi 原生 JS 规范。

### 2. 本地 JS 源包与协议完美支持
- **主力本地目录直连**：深度支持加载 `D:\code\ok影视js源\my`，启动自动探测并优先挂载。
- **本地 ZIP 离线包**：支持任意结构 ZIP 包导入，自动解压至应用沙盒并挂载 `clan://localhost/` 协议。
- **多层配置探测**：内置宽松容错 JSON 解析器，自动剔除注释、尾部多余逗号、BOM 头及 Base64 编码。

### 3. LogVar 弹幕全功能接入
- **默认服务器**：`https://dm.0256520.xyz/888`
- **实时抓取**：选集播放时自动匹配并拉取爱优腾芒哔等全网实时弹幕。
- **弹幕配置中心**：设置页提供弹幕开关、服务器测通、字体大小、不透明度、显示区域 (1/4屏~全屏) 与速度微调。
- **播放器内控**：支持一键开关弹幕与**手动搜索匹配弹窗**（可针对特殊剧名或集数手动修正搜索）。
- **文字抗眩光描边**：弹幕文字自带高对比黑边，高亮画面同样清晰可读。

### 4. 完美播放器体验 (向 OK 影视靠齐)
- **多端触摸手势**：
  - **左侧垂直滑动**：调节屏幕亮度（屏幕中央显示亮度 HUD 百分比）。
  - **右侧垂直滑动**：调节系统音量（屏幕中央显示音量 HUD 百分比）。
  - **水平滑动**：快进/快退进度（屏幕中央显示 `[+30s] 目标时间/总时间` 预览）。
- **横屏右侧抽屉面板**：全屏播放时点击“选集”，在右侧平滑滑出半透明选集与线路切换抽屉，**不退出全屏即可无缝换集**！
- **画面比例与倍速**：支持 16:9、4:3、适应原比、全屏拉伸铺满、居中裁剪；支持 0.5x ~ 2.0x 任意倍速切换。
- **断点记忆续播**：自动持久化记录每部影视各集播放进度，再次打开自动弹出恢复提示并秒级续播。
- **同名源秒搜换源**：详情页内嵌一键全网同名片源并发秒搜，快速换源。

### 5. 沉浸式电视直播 (LiveView)
- **多分组频道管理**：支持央视、卫视、地方、港澳台等多级分组。
- **多线路无缝切换**：每个频道支持多条直播流并发容错切换。
- **OSD 换台指示器**：换台时展示半透明频道卡片（台号、台名、当前线路），4 秒后自动平滑淡出。
- **遥控器按键映射**：方向键上下换台，左右切线路，OK 键唤起左侧频道抽屉。

### 6. TV 遥控器与多端焦点优化
- **专属高亮焦点组件 (`TvFocusable`)**：遥控器方向键导航时，当前获焦卡片呈现 OK 影视标志性**金琥珀发光边框 (`#E5A00D`)** 与弹性缩放动画，并自动平滑滚动居中。
- **防误触退出机制**：主界面连续两次按返回键方可退出应用，避免遥控器误触闪退。

## 二、部署替换步骤

1. 下载下方的 `lib.zip` 与 `pubspec.yaml`。
2. 将 `pubspec.yaml` 覆盖到你的项目根目录 `D:\code\ftv\pubspec.yaml`。
3. 删除原有 `D:\code\ftv\lib` 文件夹，将 `lib.zip` 解压到 `D:\code\ftv\lib`。
4. 在终端中运行：
   ```bash
   flutter pub get
   flutter run
   ```
